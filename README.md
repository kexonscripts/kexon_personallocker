kexon_personallockerGive every player their own persistent personal storage with kexon_personallocker. This character-based locker system lets players securely store items, weapons, and valuables at physical locker locations placed around your map — with full upgrade paths, money-based economy, and complete Discord audit logging built in.Each locker is tied to the player's character identifier, meaning their storage persists across sessions, reconnects, and restarts. Players interact via ox_target — simply walk up, target the locker, and choose to open their stash or upgrade their capacity. Opening pulls up a native ox_inventory stash with full server-side validation, so there's no client-trusting exploits.Storage is fully upgradeable. Players start with 50 slots and 100,000 weight, and can expand up to 100 slots and 250,000 weight by spending in-game cash. Bulk upgrades let players buy 1 to 10 upgrades at once through a clean input dialog, with prices and increments fully configurable. Maxed-out capacities are handled gracefully with clear notifications.Every action is logged to a Discord webhook with a complete audit trail. You'll see when a locker is opened — including the player, identifier, and current capacity. You'll see upgrades with the type, amount, cost, and new total. And thanks to a real-time swapItems hook, you'll get item-by-item logs for every deposit and withdrawal — item name, quantity, and direction, all timestamped. The webhook name and avatar are customizable to match your server brand.Place as many locker zones as you want — each with configurable coordinates, box size, and rotation. The database table auto-creates on first startup, so there's no manual SQL import required. Just drop the resource in and it's ready.REQUIREMENTS
ESX (es_extended)
ox_lib
ox_inventory
oxmysql
PERFORMANCEAll storage logic runs server-side through ox_inventory's native stash system. The client only handles target interaction and the upgrade dialog, keeping resource usage minimal and the system fully exploit-resistant.
